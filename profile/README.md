# Still Systems, LLC

Still Systems builds **TreeResolve**, a local-first Visual Studio Code extension and CLI for deterministic, syntax-aware merge conflict resolution. Parsing and merge work run on your machine. Paid subscriptions are billed through Paddle as Merchant of Record.
